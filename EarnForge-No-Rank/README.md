# EarnForge — final prototype

Rank/Leaderboard has been removed.

Features:
- Home / virtual earnings
- Tap reward system
- $5 tap limit resetting at 6 AM
- Energy system
- Energy Capacity +5 per upgrade
- Recharge Speed -10 minutes per upgrade
- Upgrade prices double after each purchase
- Daily tasks
- Monetag Rewarded Interstitial hook
- Ads before task rewards and upgrades
- $100 minimum withdrawal UI with progress bar
- Profile

The displayed balance and withdrawal are virtual game values in this prototype and do not process real payments.
